# 📚 Tuition Manager

**Tuition Manager** is a modern Android application built for private tutors and coaching teachers to manage their complete tuition workflow from one place.

It helps teachers organize students, class schedules, attendance, monthly fees, payments, examinations, marks, reports, and tuition-center information with a clean and professional interface.

## ✨ Features

### 👨‍🎓 Student Management

* Add, edit, and delete students
* Student ID and personal information
* School/college, class, section, and roll number
* Parent/guardian information
* Contact details
* Subjects and monthly fees
* Active/inactive student status
* Student profile and details

### 📅 Class & Schedule Management

* Schedule classes
* Set date and start/end time
* Assign subjects and students/groups
* Online/offline class support
* Add class location and notes
* Track scheduled, completed, and cancelled classes
* Calendar view

### ✅ Attendance

* Record student attendance
* Present, Absent, Late, and Excused statuses
* Attendance history
* View attendance by student, class, or date

### 💰 Fees & Payments

* Manage monthly tuition fees
* Record payments
* Track paid, partially paid, due, and overdue amounts
* Payment history
* Payment methods including Cash, bKash, Nagad, Bank, and Other
* Receipt numbers
* Due-payment reminders

### 📝 Exams & Results

* Create examinations
* Set total and passing marks
* Record student marks
* Automatically calculate percentage and grade
* Add remarks
* View exam results and student performance

### 📊 Reports

* Professional tuition reports
* Student, attendance, payment, and exam information
* Organized data for easier record keeping

### 🔔 Notifications

* Class notifications
* Fee reminders
* Exam-related notifications
* Customizable notification preferences

### 💾 Backup & Restore

* Export tuition data as backup
* Restore previously backed-up data
* Helps protect important records when changing devices

### ⚙️ Teacher Profile & Settings

* Tuition center name
* Teacher name
* Phone, email, and address
* Currency configuration
* Default monthly fee
* Notification preferences

## 🚀 Getting Started

### Requirements

* Android Studio
* Android SDK
* JDK 11
* Android device or emulator

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/tuition-manager.git
```

2. Open the project in **Android Studio**.

3. Let Gradle sync and download the required dependencies.

4. Configure the required environment variables using `.env.example`.

5. Build and run the application on an Android device or emulator.

## 📱 Designed For

Tuition Manager is designed especially for:

* Private tutors
* Home tutors
* Coaching teachers
* Small tuition centers
* Teachers managing multiple students
* Tutors who need organized fee and attendance records

## 🎯 Project Goal

The goal of Tuition Manager is to replace scattered notebooks, spreadsheets, and manual records with a single digital management system that makes everyday tuition administration faster and more organized.

## 🔒 Data

The application uses a local Room database for storing core tuition records. Users can also create backups and restore their data when needed.

## ⚠️ Note

This project is intended for educational and productivity purposes. Always keep appropriate backups of important student, payment, and academic records.
